## Known hook name mismatches

| Expected (wrong) | Actual (correct) | operationId in spec |
|---|---|---|
| useListDocuments | useListAllDocuments | listAllDocuments |

**Why:** The spec uses operationId `listAllDocuments` (to distinguish from `listCaseDocuments`) so Orval generates `useListAllDocuments`.

**How to apply:** When importing document list hooks, always use `useListAllDocuments`. Check operationId in openapi.yaml when hooks don't match expectations.
